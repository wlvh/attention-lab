实验课 05：把单层学习扩展到各层¶

第四课只给第 14 层训练了索引器。这一课让完整 Qwen3-0.6B 为每个目标层分别提供 Q/K/V，再用这批固定数组训练该层自己的索引器。训练完前一层，不把它接回模型改变下一层的输入；各层教师都来自原完整读取路径。

项目称这一步为 G3b-lite：各层索引器训练。27 层新训练，第 14 层直接复用相同条件下已训练的参数，合计提供全部 28 层索引器。主体冻结，旧 48 份资料用于训练，旧 16 份只作开发诊断；另有 32 份新资料留给第七课的最终答题。

每份 T1 资料要求按编号取一个四位值。读取规则继续保留开头 4 个和最近 64 个位置，再按请求第一步长度的 1/8 固定额外名额。C 在剩余位置均匀随机选；D0 用初始参数；D 用训练后参数；R 用完整教师权重选。索引从主 RoPE 前 Q/K 投影到 32 维，索引空间不额外旋转，配置记作“索引位置设置 P0，r=32”。

下面先看一层怎样提特征、更新和评测，再比较各层指标。默认只读归档和重算图表，不启动模型或训练。

2. 逐层训练，保持主模型不动¶

对当前目标层，主模型在 MPS/bf16 上完整处理每份资料和问题，只保存这一层后缀倒数第 24/16/8/1 个位置的 Q，以及对应历史 K/V。本批固定模板中，四个位置分别是问句里的“数值”“四位”、用户消息结束标记后的换行、空 thinking 模板后的两个换行；后缀共有 35 个 token，其中问句占 26 个。64 份该层特征 detach 后存放在 CPU 内存；教师在 CPU/fp32 计算。

随后更新这一层新增的 Wq/Wk。以第 1 层为例，一轮依次读取 48 份训练资料：每份取四个查询位置，每个查询有 8 个 KV 组；用当前 Wq/Wk 给候选历史位置打分，将候选 softmax 与完整注意力提供的候选分布比较，汇总有效查询/组的 KL，再做一次参数更新。固定做 50 轮，旧 16 份开发资料不进入这些更新。

评测时拿同一份保存的 Q/K/V 分别运行 C、初始索引 D0、最终索引 D 和教师选位 R。各方法选好位置后，合并首部/近期必留位置，用原主注意力权重在入选集合内重新归一化并加权 V，再与完整读出比较。这份局部读出在比较后结束，不会送入第 2 层。

第 1 层参数和指标保存后，释放临时特征；处理第 2 层时，再让未改的完整模型提供第 2 层特征。依此处理其余层，第 14 层直接复用原参数。各层有各自的 Wq/Wk，训练好的前层没有部署进来，也没有同时通过一个整模型损失更新 28 层。训练在 MPS/fp32，最终局部评测在 CPU/fp32。

每层只保留预先指定的资料序号 0 和 48 的完整特征，其余完整数组记指纹后释放。精简归档保留输入、参数、指标等证据，但不能直接重做全部特征级审计。

def layer_config(cfg, layer):
    return dict(cfg, layer_index=layer, index_seed=cfg["index_seed"] + layer - 13,
                uniform_seed=cfg["uniform_seed"] + layer - 13)

def train_layer(features, docs, cfg, guard, output_dir, epochs, progress=lambda epoch: None):
    import time
    from .campaign import write_json
    output_dir = Path(output_dir)
    trained = TrainableIndexer(r=cfg["r"], seed=cfg["index_seed"], device=cfg.get("training_device", "mps"))
    initial = TrainableIndexer(r=cfg["r"], seed=cfg["index_seed"])
    initial.save(output_dir / "index_initial.npz")
    rows = [list(query_rows(features[d["doc_id"]], cfg)) for d in docs if d["split"] == "train"]
    eligible = sum(int(r["eligible"].sum()) for group in rows for r in group)
    skipped = sum(int((~r["eligible"]).sum()) for group in rows for r in group)
    optimizer = torch.optim.Adam(trained.parameters(), lr=cfg["learning_rate"])
    rng = np.random.default_rng(cfg["shuffle_seed"])
    trace, step_seconds = [], []
    for epoch in range(1, epochs + 1):
        losses, gradnorms = [], []
        for i in rng.permutation(len(rows)):
            guard.check()
            begin = time.monotonic()
            optimizer.zero_grad(set_to_none=True)
            loss = loss_for_document(trained, rows[i])
            if loss is None:
                continue
            if not torch.isfinite(loss):
                raise RuntimeError("nonfinite loss")
            loss.backward()
            if any(p.grad is None or not torch.isfinite(p.grad).all() for p in trained.parameters()):
                raise RuntimeError("disconnected/nonfinite index gradient")
            norm = torch.nn.utils.clip_grad_norm_(trained.parameters(), cfg["gradient_clip_norm"])
            if not torch.isfinite(norm):
                raise RuntimeError("nonfinite gradient norm")
            optimizer.step()
            if any(not torch.isfinite(p).all() for p in trained.parameters()):
                raise RuntimeError("nonfinite index parameters")
            losses.append(float(loss.detach().cpu())); gradnorms.append(float(norm.cpu()))
            step_seconds.append(time.monotonic() - begin)
        trace.append({"epoch": epoch, "online_train_kl": float(np.mean(losses)) if losses else None,
                      "updates": len(losses), "gradient_norm_max": max(gradnorms) if gradnorms else None})
        write_json(output_dir / "training.json", trace)
        progress(epoch)
    trained.save(output_dir / "index_final.npz")
    changes = {name: float((p.detach().cpu() - dict(initial.named_parameters())[name].detach()).norm()) for name, p in trained.named_parameters()}
    if eligible and min(changes.values()) <= 0:
        raise RuntimeError("eligible layer did not update parameters")
    trained_cpu = TrainableIndexer(r=cfg["r"], seed=cfg["index_seed"])
    trained_cpu.restore(output_dir / "index_final.npz")
    return initial, trained_cpu, {"eligible_rows": eligible, "skipped_rows": skipped, "parameter_change_l2": changes,
                                  "training_state": "trained" if eligible else "no_eligible_rows_initial_retained",
                                  "steps": len(step_seconds), "steady_step_seconds": float(np.median(step_seconds[2:])) if len(step_seconds)>2 else None}

3. 不把第 14 层的成功乘以 28¶

全部层都报告，灰带是复用的第 14 层。KL比较教师和索引在候选域的条件分布；coverage是入选候选保留的教师权重占候选总权重的比例；m_C是候选域在完整教师中原有的总权重。这里不数目标记录的位置。

相对 L2是在同一份完整路径特征上，比较子集与完整注意力的 o_proj 前读出。一次比较对应一个查询位置、一个 KV 组：将本组两个头的 128 维输出合成 256 维，计算少读与完整读出的差，分母为完整 256 维读出的范数。每项先在资料内平均查询/组，再平均资料。它们都是旧开发集的局部指标，不是整模型回答分数。

当某个查询/组的候选总权重 m_C<1e-4 时，这一行不参与 KL 训练，也不纳入 KL、条件 coverage 的均值。候选总权重、遗漏完整权重和局部输出 RMSE/相对 L2 仍然计算并保留。 “跳过”不表示整行数据无效，也不把未纳入的指标填成零。均匀教师下，同名额的 coverage 本就可能相近。

本批 28 层在旧开发资料上的平均 KL、条件覆盖率、局部输出相对 L2 都相对 D0 改善。这个“28/28”以层为单位、使用旧开发资料，不是 28 次独立验证，也不是 28 层共同生成通过。

4. 哪些差异值得带到真实推理中检查？¶

同一份资料在不同层拥有不同Q/K/V，因此索引器学习的是不同分布。局部误差大的层可能影响后续表示，但这里只能标记风险，不能证明它就是最后答错的原因。局部误差小也不能保证多层共同部署后答案不变。

5. 下一阶段改变了什么？¶

这里训练和评测都给各方法完整路径的同一份 Q/K/V。部署后，前层少读会改变后层输入，后层索引器面对的状态可能不同。

因此第六课 G3c 先固定同一串 token，比较各路径自己的状态；第七课 G4-lite 再用新资料让各方法自由生成。这一轮不做“轨迹修正训练”（收集稀疏路径状态再追加训练），也不按最终测试结果改模板或名额。
