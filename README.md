# Attention Lab · 注意力读取取舍实验室

**在同一份预训练权重、同一任务、同一设备下，比较完整注意力与“先筛选历史、再做主注意力”的速度、答案质量、内存和新增训练成本。**

MacBook 本地优先；Codex 实施；Python 脚本执行；Jupyter 分段解读；HTML 直接阅读。

> 当前为文档与启动工具项目。没有本项目的 Mac/CUDA 实测、Qwen 评测或索引器训练结果。原始附件中的历史实验和性能预测不算本项目成绩。
>
> 仓库由所有者于 2026-10-16 创建并明确选择公开。首次完整材料导入进行中；导入完成状态与操作入口将记录在 PROJECT_STATUS.md 和 START_HERE.md。

## 研究目标

通过可追溯的预测、真实执行和受控对照，找出索引筛选值得采用的区间与不适用的条件；负结果与证据不足同样可以交付。

首轮只实施 G0 环境预检和 G1a 单层执行可行性，不从零预训练、不租云、不启动全部模型下载。后续由实测解锁。

## 工作方式

正式实现维护在 Python 模块中，训练与测速使用独立脚本；Notebook 调用同一实现并分段讲解，HTML 提供无需重跑的阅读版。代码版本、输入配置、预测、日志、失败记录和成本分别保存。

公开仓库不提交访问令牌、账号凭据、机器身份、本地绝对路径、模型权重或未经检查的运行数据。不自动创建 Pages、改变仓库可见性或选择开源许可证。
