# 决策与修订记录

## 尚未定案，不要冒充已选择

最终模型规模；MPS可用低精度和编译路径；P0/P1；正式ρ；实际N*；局部层预算；索引是否值得继续训练；是否启用CUDA复核；正式统计方法的具体实现。这些由指定关卡的校准/能力结果决定并冻结。
