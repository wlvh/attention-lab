# 计算、状态与接口知识

本文是Codex实现时的接口规格，不表示相应函数已经存在。依据：原v3第2/5节、教材注意力计算与索引筛选部分、后续评审修订。主模块源码必须在G1b固定版本后再次核对。

## 1. 层内数据流

```text
hidden_states
  → 原 q/k/v 投影
  → 原 q_norm / k_norm
      ├─ q_pre / k_pre → 索引投影 → 索引P0/P1 → u / z
      └─ 主 RoPE → q_main / k_main
  → 新 k_main / v / z 各追加一次
  → 策略选原历史位置
  → gather本组主K/V → 原主Q重新打分 → 汇总V
  → 原o_proj → 原残差/前馈 → 下一层
```

预训练权重是旧计算结构的参数，不是结构改写后的能力保证。封装`self_attn`而不是修改已安装库；使用原投影对象，不复制或重新初始化主体参数。

## 2. 建议统一张量语义

B批量、G为KV组、H为Q头、h=H/G、T为本次输入长度、N合法历史总长度、C分配容量、d头维度、r索引宽度。

| 对象 | 建议语义形状 |
|---|---|
| q_pre / q_main | [B,G,h,T,d] |
| k_pre / k_main / v 新片段 | [B,G,T,d] |
| 主KV分配 | [B,G,C,d]，每层独立 |
| u | [B,G,T,r] |
| z索引表 | [B,G,C,r] |
| decode名单 | [B,G,K_actual]，原位置int索引 |
| group读取结果 | [B,G,h,T,d]，最终还原原H*d排列 |

这只是内部接口建议；最终以所用Qwen源码布局为准，映射需单测。GQA允许本组多个Q头共用KV，不把持久缓存repeat到H。性能后端若临时展开，要计入临时量与实测开销。

## 3. 固定集与候选

给定query_pos和valid_length，合法位置满足0≤j<valid_length且j≤query_pos。先形成F=首4∪最近64，去重。候选域为合法域减F。D只对候选域top-k；之后合并F，按原位置读取。不要先对全域top-k后随意去重造成预算缩水。

多个策略在同一ρ档位下actual_count一致。B取最近actual_count，C/D同F与候选数。k=0（仅F）、候选不足、F重叠、空候选都要定义并测试。若完全没有合法记录，应在接口层明确报错，而非softmax全负无穷生成NaN。

为了编译可设固定上限和有效槽遮罩；占位槽不得重复计权，不能把pad位置当真实token。测量时报告scanned_length、selected_count和allocated_capacity，不能只报告token名义长度。

## 4. cache身份与恢复

身份至少包含主体model/tokenizer revision、实际权重标识、输入token序列、主/索引位置规则、精度、索引参数版本、轨道和层号。缓存ID相同是计算兼容检查，不是用户权限证明。

资料前缀在dense路径产生，问题尚未进入。顺序多问时：保存prefix_length，完成一个问题后回退KV与z有效长度，再覆盖新后缀；分配容量不变。尾部旧数字可以还在，但必须无法被选中或读取。真并发分支需隔离写入或copy-on-write，第一版不做并发。

参数更新后以前算的z失效；主模型更新不在本轮。若稀疏路径已改变高层状态，不能把它的后缀KV拿给dense自由续写当成同一个历史。

选出下一个token时，它自己的KV尚未产生；下轮送回模型才追加。EOS是否入cache与测量时点要在run元数据注明。

## 5. 教师与梯度

dense主体正常前向，只取最多8条查询行，保留其主RoPE后Q/K用于教师重算；q_pre/k_pre用于索引。不要用索引空间分数替代主教师打分。教师按每头softmax，再在KV组内平均、扣除F并重新归一化。

使用detach/no_grad切断主体，但新线性层前向与KL在可求导上下文。不要把整个训练循环包进no_grad。若使用inference_mode生成特征，需确认其张量能作为索引训练保存的输入，必要时在训练上下文外转为普通detach克隆；以实际梯度测试为准。

先测试：主体参数差=0、主体grad=None；索引参数有梯度且变化；固定样本KL可下降；只有整数indices传到答案的路径不承诺答案梯度训练索引器。

逐层损失累积再更新；新W下重算z。记录有效训练行数、跳过行数、主体前向token、墙钟时间和峰值，不用可训练参数量代替总成本。

## 6. 正确性测试清单

| 测试 | 必须得到的关系 |
|---|---|
| 所有位置入选 | 对应完整注意力，先CPU FP64小例子再目标dtype容差 |
| 固定子集gather与dense mask | 同一Q/K/V、合法位置和缩放下对应 |
| 改变未来/未写槽 | 当前结果不改变 |
| 非方阵query长度1、history长度>1 | 合法历史全部可读，不套错左上因果遮罩 |
| 原位置2、9入选 | 不重编号成0、1，不再次主RoPE |
| 一次/分块Prefill | 主KV与z均对齐 |
| append/rollback | 长度一致，回退后旧后缀不可见 |
| 请求分支 | 不产生跨请求写别名污染 |
| P0/P1 | 主RoPE路径相同，只有索引变式改变 |
| 连续128步 | 不重复追加，k规则稳定，重编译与内存可解释 |

数值容差先在明确参考路径和dtype上预设；不能为掩盖实现错误扩大容差。贪心文本相同不证明logits正确；最小分差接近舍入时文本分歧也不自动证明缓存错误。
