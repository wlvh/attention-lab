# 测量与结论协议

## 1. 先划清比较对象

所有加速比必须落在同模型、同设备、同dtype、同实际长度/输出规则、同缓存容器上。Mac与CUDA分别出表。A-step是机制对照，A-best是正常已知输入批量计算的性能基线。D不支持批量问题时如实承担这部分成本。

随机张量微基准不是语言能力评测，随机token的单步测量也不是自由生成质量。完整模型需要真实权重、实际层内其余工作，不能用单层时间简单乘层数当实测。

## 2. 运行前

冻结config与prediction；记录run_id、UTC、源码SHA、dirty diff、模型revision、tokenizer及数据hash。非干净代码允许运行调试，但正式结论必须保存精确快照并能重放。

确认电源/睡眠、并发GPU任务、CPU线程设置、后端fallback与编译状态；实际机器内存不由开发容器代报。warm-up与编译费用单列。数据准备是否计时、索引构建是否计时明确到字段。

## 3. 微基准

A与D输入相同。D包括索引查询投影、新z更新（完整step范围时）、历史索引扫描、top-k、名单合并排序、gather与子集注意力。若微基准从已有u/z开始，标为read-stage，不把未计费用当零；G1b必须全step计入。

热工作集：重复同一组；轮换工作集：轮换不同KV/z，记录组数、字节数、是否超过可确认的缓存容量。Mac缓存结构不套4080常数；不能证明缓存未命中时，只称“轮换工作集”，不叫纯DRAM实测。

强制均匀/成簇名单仅作gather敏感性诊断；真正D须现场打分选择且记成本，不以预存名单冒充D。

正式计时边界同步设备。需要控制Python侧延迟时同时保留进程墙钟与设备剖析。不要逐小算子同步主结果，分段剖析另跑。记录编译失败、graph break、重编译和实际内核，名字叫compile不证明已经融合。

重复次数先预检校准；重点设置计划5个独立进程，预热20、测50。p95样本量有限，保留原始序列与样本数，不把孤立尖峰或最佳一次当总体。内存预分配与模型加载应在微基准计时外，另列冷启动成本。

## 4. 三口径与生成长度

- hot_ms：资料缓存就绪之后，问题处理+生成。
- cold_ms：资料Prefill+索引构建+hot（重叠阶段不能重复相加，端到端计时为准）。模型加载另报。
- amortized_ms：同资料1/4/16问，计首次构建与每问恢复；A享有相同复用。

质量用自由生成真实停止；性能还需固定同一给定后缀/长度的诊断，防止少回答、早EOS看起来快。两种测试不混为一个指标。保留实际生成token数、错误格式和截断状态。

## 5. 质量与统计

训练/校准/测试按完整资料包切分。每个doc_id在所有策略上成对运行。多个问题来自同资料时以资料包为聚类单位。保留A对D错、A错D对、同对、同错四格，而不是只保存总体准确率。

D-A为正表示D更好；非劣阈值-0.02。测试前冻结单侧/双侧、置信度、配对方法及多配置处理。按资料包bootstrap是一般方法，但全同/很少分歧时需采用预先规定的稀少事件界限或保守精确方法。不要全同bootstrap得到[0,0]后宣称完全确定。

“256份的区间半宽固定为3–4pp”不是当前约定。精度取决于分歧结构与聚类。区间跨阈值写证据不足，不换一种方法反复算到通过。

一个计划参考：独立资料、每包单一二元判定、n包零次A对D错时，对有害事件概率的一侧95%上界为1-0.05**(1/n)。这不是任意聚类或连续评分的万能区间；最终实现需单独测试与预注册。

多个ρ只在校准选择，冻结最多两档；每个主要模型/任务/长度分别报。汇总指标和重要子组都保留，不能总分掩盖双证据退化。

## 6. 分层解释

记录候选域原始质量m_C、条件coverage c、遗漏完整质量m_C(1-c)、教师熵、与R差距、局部输出绝对/相对误差、真实轨迹变化。跨所有层的简单均值只是概览，不能替代分层分组表。

均匀M个候选时coverage=k/M，C/D/R都可能相同；此时不能以“D不超过随机”单独判训练失败。高coverage也不保证答案不变。局部结构解释必须有原始位置例子与输入反事实支撑，不把注意力图当因果证明。

## 7. 验收与失败归类

candidate_effective：预先选定配置下，质量差≥-2pp、hot耗时降低≥10%，相应区间支持；同时明确A-best和cold是否受益。

其他状态：correct_but_not_faster、quality_loss、baseline_too_weak、backend_unsupported、memory_limit、budget_stop、insufficient_evidence。门槛用于本项目投资决策，不推成架构普遍上限。

每关传递完整可行组合表。修改索引r、层策略、KV组共享、精度或后端，需重测受影响的性能组合。
