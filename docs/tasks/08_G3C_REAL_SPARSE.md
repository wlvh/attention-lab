# G3c：真实稀疏推理接入与状态差异

依赖：G3b-lite 的完整28层参数、可核验的固定上游提交及检查点hash。待审PR可作为明确依赖，不等待合并；上游正确性问题会使受影响的下游证据失效并重新核对。

**固定条件。** Mac/Qwen3-0.6B、主体bf16、P0/r32、ρ=1/8、索引float32；训练后参数固定。先单层接入，再28层；资料仍完整Prefill，从问题第一个token开始各方法独立推进。A/B/C/D0/D不借用A的新后缀缓存。D0与D使用相同索引精度、缓存/读取实现；B/C/D0/D同一F和名额。

**实现验收。** 先CPU验证单层与全层的全选等价（同Q/K/V、原位置和因果范围）、训练参数加载、fp32索引与bf16主体分离、缓存克隆/回退与独立后缀。索引缓存必须绑定参数身份，参数变化不能继续使用旧z；冻结参数之后才可复用。再做小批真实检查，不恢复Metal/CUDA或内核优化。

**诊断。** 仅用旧开发资料48–51，预先固定16个延续token。A先生成一条实际序列，各方法随后接受完全相同的问题/延续token，比较每层Q/K、局部注意力输出和最终logits的变化。强制序列只是对齐计算位置的诊断，不判答题成绩，不输入正确答案充当生成结果。报告单层接入与全层接入的区别；R只在少量固定特征上诊断，不进入廉价速度曲线。

**预测。** 完整路径上学到的索引器在实际稀疏路径中可能遇到不同Q/K；局部覆盖率改善可能被跨层累计偏差削弱。单层接入可能比全层接入更接近A，但不预设必然关系。

**交付、预算与后续。** 保存真实运行源码/参数/输入序列hash、逐步局部指标、共享预算账、Notebook讲解和待审PR。三阶段共享14400秒，现金0；同一阻塞最多两次有依据修复。只测差距，不做轨迹修正训练、不调ρ/模板。正确性通过后固定本阶段提交，继续G4-lite自由生成与成本评测，不要求先提高准确率。

数值定位与一次修复（正式质量评测前）：`g3c-20261018T153617Z`在单层全选处停止，bf16 logits最大绝对差1.40625、最大相对L2 0.09320，argmax虽一致仍判失败。前13层状态完全一致，第14层首次读出的局部向量相对差约0.0028，指向选中集合的排列改变了有限精度聚合。第一项有依据修复是所有本轮B/C/D0/D选位后按原位置升序排列，保留相同集合、分数和名额；之后仍走同一gather及主注意力，不以全选旁路逃避检查。旧路径默认不改。固定容差不放宽；CPU检查同集合、升序及float64输出等价后再重试。失败run原样保留，共享账计费。
