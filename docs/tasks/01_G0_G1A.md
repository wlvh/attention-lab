# 首个实现任务：G0 + G1a，Mac本地

状态：**待执行**。这是首轮唯一预先解锁的实验实现任务，不等于当前脚本已具备GPU基准功能。

## 目的

证明所需运算在用户Mac上可以正确执行，并找到索引子集路径是否有值得继续的运行区间。先不训练、不加载Qwen、不构建完整服务。

## 构建顺序

1. `task/g0-g1a-mac`分支。运行现有源校验与工具测试；保留原件。
2. 隔离环境，真实采集MPS设备与关键运算；依赖通过后锁定。CPU FP64小例子为参考，MPS FP32和低精度分别验收。禁静默fallback。
3. 在`src/attention_lab/`实现清晰的dense_reference、dense_mask_reference、gather_attention、grouped_indexer最小函数。先独立测试形状、因果、候选域、全部/零候选、全选及同子集等价。
4. 实现单层读阶段微基准。A使用适用的实际优化路径；D包含u准备、索引打分、top-k、名单处理、gather、子集主注意力。明确读阶段与完整step未计部分。
5. 8K/16K/32K，ρ=1/32、1/8，r=32，先普通执行；编译能力实测后两边同时加。小规模32/128/512用于正确性，不当速度主证据。
6. 热工作集与轮换工作集分别测；内存预算约束，先计算再申请。均匀与成簇名单是单独诊断，不代替D实选。
7. 原始JSONL、配置、预测、版本、剖析；生成第一课Notebook及HTML。

## 先写预测

没有本机带宽与执行效率前不填MPS毫秒预测。写明短N可能输在固定开销，较长N提供更多KV字节节省，但top-k/gather、内核、缓存层次和CPU提交重叠均可能改变方向。
