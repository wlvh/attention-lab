# G3b-lite：各层索引器训练

2026-10-18 新阶段授权。依赖：PR #12 已合并到 main `0dd6b73`，Issue #11 已关闭。此任务与 G3c、G4-lite 连续执行，后续 PR 待审不阻止使用固定上游提交继续研发；只授权合并 PR #12。

**研究问题与固定条件。** 沿用 Mac、现有环境及 Qwen3-0.6B 固定 revision；主体 bf16/MPS、全部完整读取。28 层均提供 P0/r32 索引器，固定 ρ=1/8、一个训练种子，索引参数/计算 float32。各层初始化种子由 `1803 + layer_index - 13` 派生，属于一个实验种子，不搜索种子。第14层与 G3a 的初始化、48份训练、50轮、优化器及查询位置一致，复用已完成参数与原始特征并校验 hash，来源单列；其余27层训练。

**资料与冻结。** G3a 的前48份用于训练，后16份已被分析，只称开发诊断，不再称独立验证。用种子2026101804预先固定32份全新T1最终测试（2048±64 token，前/中/后目标平衡），与全部既有资料 hash 去重。最终测试只在 G4-lite 自由生成时使用，不参与训练、轮数/层/提示选择。完整配置为 `configs/mac_g3bg4lite.json`，提交后不为了预算暗改定义。

**训练与记录。** 复用 G3a 的教师构造、KL、梯度分离及 Adam lr=0.001、clip=1、固定50轮、每资料4条查询。本机仅余约23GiB磁盘，因此逐层提取并在CPU内存保留该层64份特征，训练/评估后释放；每层只落盘固定审计资料0/48的完整特征，其余完整数组不保留但记录哈希。全部指标、参数、输入和版本保留，可从固定模型重提特征；不声称精简归档足以重做全部特征级审计，不同时保留全资料全层 attention。每层报告训练/开发 KL、m_C、条件coverage、遗漏完整权重、局部输出误差、跳过计数和C/D0/D/R。全部层均报告；无有效教师行则保留初始参数并注明，不能伪称已训练。

**预测。** 多数层的训练拟合会改善；层间改善幅度和剩余局部误差可能不同。第14层的局部成功不保证各层都改善，也不保证共同部署后回答恢复。均匀教师或很小m_C的层不以“没超过随机”单独判失败。

**验收。** CPU检查采集与原单层实现一致、来源/划分、梯度只到索引器、每步重建z、训练参数与文件恢复、全部层记账；真实小批预检覆盖第1/28层。每层冻结参数和原始指标、源码/config/数据/权重hash、主体未变证据齐全。正确性通过且记录完整即可交PR并继续G3c，不以所有层变好为门槛。

**预算与后续。** 三阶段共同新增14400秒设备运行预算（预检/失败/重试均计入）；先小批测算，G3b开始正式批次前至少为推理/评测预留3600秒。现金0，内存80GB预警/100GB硬停，swap新增>1GB停。每一阻塞最多两次有依据修复；预计无法完成下一批则保存部分结果和缺口，不能缩轮数冒充完成。提交待审PR、记录固定head，随后建立依赖分支继续G3c，不自行合并。
