# G3a：单层索引器可学习性验证

跟踪：[Issue #11](https://github.com/wlvh/attention-lab/issues/11)。预测首次提交：`ee7e2f1`。

2026-10-18 运行前登记。范围依据：用户本轮给出的缩减 G3a 任务；旧任务中“不训练”的停止点仅对此项解除，完整 G3–G5 仍未解锁。基于 main `d2fc4ad`，不引入 PR #6–#9 代码，不自动合并 PR #10。

**问题。** 冻结 Qwen3-0.6B，在同样的读取名额下，训练一个中间层的索引器，能否在新资料上更接近完整注意力的读取分配？这不是整模型答题或速度实验。

**固定条件。** 沿用现有 Mac 环境、模型及 tokenizer revision `c1899de289a04d12100db370d81485cdf75e47ca`。主体 bf16/MPS、全部完整读取，无自由生成；第 14 层（索引 13）的 8 个 KV 组索引器采用既有 P0、r=32。只更新该层 Wq/Wk，共 98,304 个 float32 参数。主体梯度关闭，特征 detach，其他层无训练或稀疏部署。训练每步重新计算索引 z，不跨参数更新复用。

**数据。** 复用 v2 T1 生成器与提示，另用种子 2026101803 生成 64 份约 2K 资料，命名空间 G3a；前 48 份训练、后 16 份留出，四种目标位置循环，各集合分别平衡。核对与旧归档的资料 hash 不重合。每份抽取后缀倒数第 24/16/8/1 个位置，最多 4 条查询，不保存全层全位置注意力。问题不进入资料前缀；完整资料 Prefill 后，问题逐 token 完整读取，提供固定参照特征。

**训练。** 配置见 `configs/mac_g3a.json`。单一种子，Adam lr=0.001，无 weight decay，梯度范数上限 1；按文档训练 50 轮，每轮固定种子打乱 48 份次序。主注意力教师在保存的 bf16 特征转 float32 后重算：先逐主头 softmax，再在 KV 组内平均，去掉固定集合 F（首 4、近 64）后归一化；原始候选总权重 m_C < 1e-4 的行跳过训练并计数。优化 KL(教师 || 索引连续分布)。留出资料不用于调参、不逐轮查看，固定第 50 轮参数后一次检查。

**比较与验收。** ρ=1/8，k0 按资料前缀长度+1 固定，实际名额随合法域裁剪。C 为固定种子的均匀抽样，D0 为训练前参数，D 为最终参数，R 按完整教师权重取 top-k；全部采用同一 F、候选域、特征与名额。报告文档平均的训练/留出 KL、条件 coverage、m_C、遗漏完整权重、教师熵、逐组和逐文档差异、注意力输出在 o_proj 前的绝对 RMSE/相对 L2。C 的 KL 指均匀全候选分布；R 仅为选位诊断，KL 不适用。R 的覆盖最优不等于输出误差最小，更不是任务质量上界。

**运行前预测（原文保留）。** 预计训练 KL 下降；留出 KL 与 coverage 能否同步改善不确定。若留出平均 KL 低于 D0 与均匀分布，且同名额 coverage 高于 D0 与 C，记为本轮单层可学习性的描述性支持；局部输出误差独立报告，退化不得隐藏。没有达到这些方向也交付失败或证据不足，不调留出集重来，不宣称泛化保证或自动扩展。展示完整留出结果，并按最终查询的 coverage 差选最大改善/最差案例，明确它们不是随机典型样本。
